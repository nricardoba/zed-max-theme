# Max Theme

A dark theme for [Zed](https://zed.dev) with syntax highlighting based on One Dark.

## Credits

- [Min Theme for VSCode](https://github.com/miguelsolorio/min-theme) by Miguel Solorio: Original inspiration.
- [Min Theme for Zed](https://github.com/phibr0/zed-min-theme) by Phillip Bronzel: Inspiration when I switched to Zed.
- [One Theme for Zed](https://github.com/zed-industries/zed/tree/main/assets/themes/one) by Zed Industries: Inspiration for syntax.
